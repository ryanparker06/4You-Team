# 4You Team website

A JavaScript-powered website with no frameworks or build step. The content and pages are rendered by `app.js`, with styles in `style.css`.

## Preview locally
Open `index.html` in a browser. Links use URL hashes, so project pages also work on GitHub Pages without server configuration.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `4you-team`.
2. Upload `index.html`, `app.js`, and `style.css` to the **root** of the repository and commit the files.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main**, folder **/(root)**, and click **Save**.
6. Wait for GitHub Pages to deploy. Your site will be at `https://YOUR-USERNAME.github.io/4you-team/`.

## Customize
Edit the `projects` and `staff` arrays at the top of `app.js` to change names, descriptions, and profile details. The project pages are automatically generated from the project data.
